## 🛠️ Технологии

- **HTML5** — семантическая разметка
- **CSS3** — CSS Variables, Flexbox, Grid, анимации, абсолютное позиционирование
- **JavaScript (ES6+)** — меню, карусель, навигация, lightbox (модальное окно)
- **Google Fonts** — Jost
- **Локальные шрифты** — Patsy Sans

---

## 📱 Адаптивность

Сайт адаптирован под следующие брейкпоинты:

| Breakpoint | Изменения |
|------------|-----------|
| **≤1440px** | Отступы 120px, шрифты меньше |
| **≤1200px** | Блок ОБО МНЕ на всю ширину, 2 колонки проектов |
| **≤900px** | Мобильное меню (бургер), SOFT/HARD в столбик |
| **≤640px** | 1 колонка проектов, иконки 40px, чибик 200px |
| **≤480px** | Минимальные отступы 16px, шрифты ещё меньше |

## 🎨 Дизайн-система

### Цветовая палитра
| Цвет | HEX | Использование |
|------|-----|---------------|
| Красный акцент | `#92272F` | Кнопки, заголовки, акценты |
| Тёмный | `#2c2c38` | Текст, логотип, футер |
| Фон | `#F3F3F3` | Основной фон сайта |
| Белый | `#ffffff` | Блоки, текст на тёмном |
| Чёрный | `#000000` | Текст на светлом фоне |

### Шрифты
| Элемент | Шрифт | Начертание |
|---------|-------|------------|
| Заголовки | **Patsy Sans** | Regular (400) |
| Основной текст | **Jost** | Regular (400), Medium (500), Semibold (600), Bold (700) |
