# Сайт-портфолио Valentina

**Digital-художник и графический дизайнер**

---

## 📋 Описание

Сайт-портфолио для Valentina — digital-художника и графического дизайнера. Адаптивный одностраничный сайт с каруселью проектов и страницей для каждого проекта.

---

## 🚀 Просмотр

Сайт доступен на GitHub Pages: [https://vallusha-ivanova.github.io/portfolio/](https://vallusha-ivanova.github.io/portfolio/)

---

## 📁 Структура файлов

```
Portfolio/
├── index.html              # Главная страница
├── project-page.html       # Страница проекта (шаблон)
├── style.css               # Все стили
├── script.js               # JavaScript (меню, скролл, навигация)
├── .gitignore              # Игнорируемые файлы
├── README.md               # Этот файл
│
├── PatsySans/              # Шрифт Patsy Sans
├── Poppins/                # Шрифт Poppins (резервный)
│
├── img_valentina.png       # Фотография Валентины
├── Gшапка главной страницы.png
├── фон с текстурой_1.png
├── фон с текстурой_2.png
├── Special Skills.png
├── чибик.png
├── Projects.png
│
└── Иконки программ и изображения проектов
```
